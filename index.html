Driftbed

Add natural, loop-free ambient background to audio or video. Driftbed runs locally in your browser, keeps the source file private, and lets you reproduce the same evolving sound bed whenever you reuse the recipe.

The relative-noise setting is measured below the source's robust program level. More negative values are weaker; values closer to 0 dB are stronger. The same seed, environment, duration, sample rate, pattern controls, frequency detail and algorithm version regenerate the same synthetic background. The source is never uploaded by this app.

Implementation notes

Audio uses source analysis plus a deterministic timeline dataset: exact weighted scene categories are scattered by a seeded Feistel permutation, neighboring scenes share hierarchical macro-context, and smoothly crossfaded regimes alter modal focus, spectral balance, stochastic texture, stereo width, modulation and event density. A deterministic additive spectral field superposes many independently seeded frequency components with separate magnitudes, phases, stereo phase offsets and slow drift; each scene reshapes those per-frequency amplitudes using exact weighted classes while preserving bounded total power. Source-relative level planning and peak-safe mixing are applied afterward. Every generation also emits the noise-only track. Video uses the same deterministic synthesizer with browser-native real-time capture and MediaRecorder; current Chromium browsers are recommended.
